QURAT-UL-AIN PERSONAL WEBSITE

Files:
- index.html: Home page
- gallery.html: Photo gallery page
- style.css: Shared styles for both pages

How to use:
1. Keep index.html, gallery.html, and style.css in the same folder.
2. Create a folder named "images" beside those files.
3. Add your own photos using these filenames: photo1.jpg, photo2.jpg, photo3.jpg,
   photo4.jpg, photo5.jpg, and photo6.jpg.
4. Open index.html in a browser, or use Live Server in Visual Studio Code.

The gallery displays styled placeholders until you add your own images.
The same navigation header is included on both pages.
